Problem 3: Penguin Species Discovery with K-Means¶

This notebook implements k-means from scratch in NumPy and applies it to the Palmer Penguins morphology features in penguins.csv. Species labels are held out during clustering and used only afterward for interpretation.

(c) Implement K-Means from Scratch¶

In [3]:
def _kmeans_internal(X, k, max_iter=100, seed=0, return_history=False):
    X = np.asarray(X, dtype=float)
    n_samples = X.shape[0]
    if k < 1 or k > n_samples:
        raise ValueError("k must be between 1 and the number of samples")

    rng = np.random.default_rng(seed)
    initial_idx = rng.choice(n_samples, size=k, replace=False)
    centroids = X[initial_idx].copy()
    labels = np.full(n_samples, -1, dtype=int)
    inertia_history = []

    for _ in range(max_iter):
        distances_sq = ((X[:, None, :] - centroids[None, :, :]) ** 2).sum(axis=2)
        new_labels = np.argmin(distances_sq, axis=1)

        new_centroids = centroids.copy()
        for cluster_id in range(k):
            members = X[new_labels == cluster_id]
            if len(members) > 0:
                new_centroids[cluster_id] = members.mean(axis=0)
            else:
                new_centroids[cluster_id] = X[rng.integers(n_samples)]

        updated_distances_sq = ((X - new_centroids[new_labels]) ** 2).sum(axis=1)
        inertia_history.append(float(updated_distances_sq.sum()))

        if np.array_equal(new_labels, labels):
            centroids = new_centroids
            labels = new_labels
            break

        centroids = new_centroids
        labels = new_labels

    final_distances_sq = ((X[:, None, :] - centroids[None, :, :]) ** 2).sum(axis=2)
    final_labels = np.argmin(final_distances_sq, axis=1)
    final_inertia = float(final_distances_sq[np.arange(n_samples), final_labels].sum())

    if not inertia_history or not np.isclose(inertia_history[-1], final_inertia):
        inertia_history.append(final_inertia)

    if return_history:
        return centroids, final_labels, final_inertia, inertia_history
    return centroids, final_labels, final_inertia


def kmeans(X, k, max_iter=100, seed=0):
    # Required assignment signature.
    return _kmeans_internal(X, k, max_iter=max_iter, seed=seed, return_history=False)

The spread is large enough to matter: some seeds find a strong three-species-like solution, while others split the Gentoo-like birds into two clusters and merge much of Adelie/Chinstrap. The two side-by-side clusterings therefore disagree substantially, not just on a few boundary points.

(h) Summary and Recommendation¶

The morphology data show a very strong split into two compact groups, with Gentoo separated from the other penguins, and a plausible but less clean three-cluster structure corresponding to the three recorded species. The elbow curve has its strongest bend at k=2 and a secondary bend around k=3, while silhouette selects k=2, so I am most confident in two broad morphology groups and moderately confident in a species-level k=3 clustering. Using k=3, the best fixed run in this notebook recovered the recorded species with purity around 0.91, with most errors occurring between Adelie and Chinstrap. Initialization matters: across 50 random seeds, Lloyd's algorithm landed in noticeably different local minima, so in practice I would run many initializations and keep the lowest-inertia solution. A limitation is that this analysis uses only four morphology measurements and drops rows with missing morphology values rather than modeling or imputing missingness.
